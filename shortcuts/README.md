# Siri Shortcuts

Built during M0, M5 and M6. Notes and exported links go here.

| Shortcut | Does | Milestone |
|---|---|---|
| Wake up Jarvis | Opens the Jarvis web app | M5 |
| Jarvis reminders | Fetches pending reminders from n8n and speaks them | M5 |
| Jarvis Sync | Adds new Jarvis reminders to the "Jarvis" Reminders list and reports completed ones back | M6 |
| Jarvis done | "Jarvis, done with X": marks X complete in Jarvis | M6 |

The shared secret token is typed into each shortcut by hand. Never commit it.
