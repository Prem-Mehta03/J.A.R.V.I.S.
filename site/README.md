# OAuth pages

`index.html` and `privacy.html` are copies of the two pages Google's OAuth consent screen links to (homepage and privacy policy). They are published from a separate GitHub Pages repository named `<username>.github.io`, and the same site was verified in Google Search Console.

- Keep the pages online and at the same addresses. If they disappear, Google can flag the app.
- If you change the text here, change it in the Pages repository too. This folder is only a record.
- The Search Console verification file (`google....html`) lives in the Pages repository, not here.
- If Jarvis starts sending different data to AI providers, update the privacy text to match.
