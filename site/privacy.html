Jarvis privacy policy

Jarvis is a personal assistant used only by its owner. Back to the home page.

What it accesses

With the owner's permission, Jarvis reads the owner's Gmail messages in order to classify them as important, normal or promotional and to produce short summaries.

What it shares

Short excerpts of each message (sender, subject and a brief snippet) are sent to AI model providers, currently Google Gemini and Groq, so that they can classify the message. Full message bodies are not sent.

Where data is stored

Results and the owner's own tasks, reminders and notes are stored in a database that the owner controls. Nothing is sold, shared with advertisers, or made available to any other person.

Google user data

Jarvis's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Deleting data

The owner can revoke Jarvis's access at any time from their Google account's security settings, and can delete stored data from the database directly.
